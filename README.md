# PSI1 Project

A web-based language learning application that combines elements of **Duolingo** and **Kahoot**.

## What it is

The application allows users to learn vocabulary through interactive quizzes and compete with other players in real time. Users can choose learning languages and categories, track their progress, create their own quizzes, and play with friends in multiplayer games.

## How to use it

1. Create an account or log in.
2. Choose the language you want to learn.
3. Choose a learning category.
4. Start a learning session or join a multiplayer game.
5. Answer questions and track your progress.
6. Review your results and performance feedback.
7. Create and share your own quizzes.
